# 🌦️ The Weather Machine

The Weather Machine is an interactive virtual Earth Science lab designed to help students explore how atmospheric conditions affect weather.

## Experiments

Students can work through four challenges:

- Make a Cloud
- Make It Rain
- Build a Storm
- Send a Cold Front

## What Students Can Change

Students manipulate:

- Surface temperature
- Relative humidity
- Temperature aloft
- Vertical lift
- Approaching air masses

The model responds by showing changes in cloud formation, rain, and thunderstorm-favorable conditions.

It also estimates:

- Dew point
- Cloud-base height
- Effective lift
- Atmospheric stability

## Student Lab Process

Each experiment follows a simple scientific-thinking sequence:

1. Predict
2. Test
3. Observe
4. Explain

Students can record their thinking directly in the virtual lab notebook while experimenting.

## Classroom Use

This activity is designed for a virtual Earth Science class and works especially well as a guided application lab.

Rather than simply identifying weather vocabulary, students manipulate atmospheric conditions and observe cause-and-effect relationships.

A teacher can pause throughout the activity and ask students to explain:

- What changed?
- What caused the change?
- What evidence supports your explanation?
- What would you predict happens next?

## Important Note

The Weather Machine is a simplified educational model.

Real weather systems involve many additional variables and interactions. The simulator is designed to help students understand basic relationships among temperature, humidity, lift, fronts, clouds, precipitation, and atmospheric instability.
